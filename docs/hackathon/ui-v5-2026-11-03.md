## API (staging)

- **Bütçe düzeltmesi:** `muse-spark-1.3` standart fiyatıyla ($1,25 / $4,25) eski sınır $0,069 ayırıyordu ve config kapanıyordu. Gövde artık ASCII (`asciiJson`); sınır 8.000 karakter + 4.096 token; `reasoning_effort: minimal`. Ayrılan tutar $0,0185. Tavanlar değişmedi ($0,02 / $0,20 / $2 / $10).
- **Staging'e uygulananlar:** iki ledger migration (DB boştu; yalnız ekleme). Kontrol satırı `enabled=false`, `project_ref=null`. `ai-gateway` deploy edildi, `AI_BACKEND_MODE=disabled`. Gizli olmayan ayarlar yazıldı.
- **Yanıt kontrolü:** production origin'i 403 `origin_not_allowed`; kimliksiz istek 401.
- **Hedef dosyası:** staging origin `https://localhost:8443` (yerel HTTPS önizleme); production origin'leri yasak listesinde.
- **Bekleyenler:**
  - `META_API_KEY` (kullanıcı);
  - `GET /v1/models` ile model kimliği ve zamanı;
  - `META_TOKEN_BOUND_VERIFIED` beyanı;
  - onay ve bitiş zamanı;
  - DB kontrolünü açmak;
  - staging test kullanıcısı. Servis anahtarını dosyaya yazma adımı izin denetiminde reddedildi; atlatılmadı.
- **Sonuç:** gerçek Meta çağrısı yapılmadı.
